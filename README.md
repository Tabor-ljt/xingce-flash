# 上岸闪记 · 行测条件反射训练器

为**在职考公人**打造：把行测各题型的**题眼信号 → 解题关键词 → 口诀**做成互动记忆卡片，并用「真题干识别训练 + 错因诊断」把*看到题 → 判断第一步*练成条件反射。地铁通勤、吃饭的碎片时间就能练，目标是提高真实行测得分，而不只是卡片掌握率。

当前面向 **江苏省考行测（B类为主）**，共 5 大模块、42 个题型、208 张卡片 + 47 道仿真题眼识别题。

## 功能

- 🎯 **题眼识别（V2.1 核心）**：不给提示，直接看仿真题干，8 秒内选出"第一步该做什么"；答错/超时立即反馈正确解法、关键题眼、易误判方向
- 🩺 **错因诊断（V2.1）**：答错时一键标注失分原因（不认识题型/方法选错/计算错误/漏看条件/犹豫/太慢/不会），系统按题型统计正确率、耗时、错因，生成弱项画像与补练建议
- ⏱ **反应时间记录**：识别/填空/闯关/闪卡每次作答都记录用时，弱项统计按时间加权（越近的表现影响越大）
- 🃏 **闪卡记忆**：正面题眼、点击翻面对答案，按「忘了/模糊/记住/秒答」自评，算法按记忆曲线（间隔重复）自动安排下次复习
- 🔗 **连连看**：题眼与解题关键词限时配对，训练条件反射
- ✍️ **关键词填空**：看题眼信号，四选一挑出解法关键词
- ⚡ **限时闯关**：3 分钟限时混答，连击加分，记录最佳成绩
- 🚩 **政治理论模块（V2.1）**：马原/毛中特/新思想/重要会议 + 2025-2026 时政卡（带考前有效期的时效标记）
- 📈 进度统计：连续学习天数、掌握进度、今日待复习提醒
- 🌙 暗色模式、📴 PWA 离线可用（地铁没信号也能学）、💾 进度导出/导入备份
- 🔍 题库搜索：按题眼、关键词、题型全文检索

## 更新题库

改完 `data/mod_*.json` / `data/id_*.json` 后运行构建脚本重新生成 `db.js`，并**把 sw.js 里的 CACHE 版本号 +1**（否则离线用户拿不到新数据）：

```bash
python build_data.py
```

### 卡片字段说明（mod_*.json）

```json
{
  "front": "题眼场景：题干中出现什么信号词/特征（卡片正面）",
  "back": "解法：精简、可执行的步骤或公式，不超过60字",
  "keywords": ["题眼关键词", "解法关键词"],
  "mnemonic": "口诀/记忆钩子（可为空字符串）",
  "difficulty": 1,
  "source": "来源，如：粉笔数量系统课-工程问题",
  "examYear": "2026",
  "validUntil": "2026-12-31"
}
```

- `front` 会被自动去掉「题眼场景：」前缀展示，`back` 自动去掉「解法：」前缀
- `keywords[0]` 用于「关键词填空」模式的正确答案，请把它写成最有辨识度的解法词
- `examYear` / `validUntil` 仅时政类卡片使用，展示为"⏳2026考前有效"
- 卡片 id 由构建脚本按 `模块-题型-序号` 自动生成；**同一题型内尽量不要调整已有卡片顺序**，否则学习进度会错位；新增卡片请追加在题型末尾

### 识别题字段说明（id_*.json）

```json
{
  "moduleId": "quant_data",
  "items": [{
    "topicId": "engineering（须是 mod 文件里真实存在的题型 id）",
    "stem": "仿真题干，40-100字，只到需要判断第一步为止",
    "options": ["第一步方法A", "B", "C", "D"],
    "answer": 0,
    "why": "关键题眼与依据，≤35字",
    "trap": "最容易误判成什么方法，≤25字"
  }]
}
```

识别题 id 由构建脚本按 `iq-模块-题型-序号` 生成；同样**不要调整已有条目顺序**（答错时按题型归属记录弱项，顺序变化会让历史统计指向新题）。

## 间隔重复规则

| 自评 | 效果 |
|---|---|
| 忘了 | 回到今天重新学，本场内会再次出现 |
| 模糊 | 1 天后再现 |
| 记住 | 按 1→2→4→7→15 天递进复习 |
| 秒答 | 间隔额外拉长 |

连续答对进入 3 级及以上记忆盒即标记「已掌握」。
